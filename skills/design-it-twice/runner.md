# Design runner

You are one of several sub-agents, each designing the same problem under a different constraint.
Design to your constraint wholeheartedly.
Don't hedge toward a safe middle: the differences between designs are the point.

Read the grounding first. Explore the code further where your design needs more than it gives.

Write your design as a proposal at the **sketch** level of the proposal template.
Leave out **Synthesis decision**.
Don't write implementation code beyond type and usage sketches.
